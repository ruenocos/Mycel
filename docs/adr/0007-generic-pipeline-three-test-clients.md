# 0007 Generic pipeline, proven on three test clients

**Status:** accepted, 13 Nov 2026

**Decision:** no client-specific code. The same pipeline, with only the context and page list changed, must give a sensible map for De Saak (ERP consultancy, B2B, real GSC data) and two fictional clients: Plantpost (houseplant webshop, B2C) and Praktijk Beweegruimte (physio practice, Utrecht, local). The fictional clients use real DataforSEO data, page fixtures instead of WordPress, no GSC, and one planted cannibalisation pair each. Part of the phase 2 gate.

**Why:** if it only works for De Saak it's a consultancy script, not a product.
