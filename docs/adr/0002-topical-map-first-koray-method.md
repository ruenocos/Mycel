# 0002 Topical map first, Koray method, data before LLM

**Status:** accepted, 13 Nov 2026

**Decision:** the first feature is the topical map (Koray's 23 steps; MVP covers 1-14 and 20). Built from public material only (his SOP and Search Engine Land articles), not the paid course. Data (GSC, DataforSEO, site crawl) drives the map; the LLM labels, scores and explains, it doesn't invent the structure. Quick wins come later, on top of the map.

**Why:** the map is the method's core and the hardest thing to get right; everything else builds on it.
